# Product Analytics with SQL (Funnel,Cohort Retention,Anomaly Alerts)-theLook eCommerce

## Overview
This Portfolio Project demonstrates how SQL to answer end-to-end Question:
- **Where do users drop off the purchase?** (strict conversion funnel + time-to-convert)
- **Do customers return and buy again?** (cohort retention)
- **Are there abnormal revenue spikes/drops that require investigation?** (rolling z-score alerts)

The analysis is built on Google BigQuery’s public **theLook eCommerce** dataset and emphasizes:
**defensible metric definitions, CTEs, window functions, and actionable recommendations**.
